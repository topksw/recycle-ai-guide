API 설정

키를 등록하지 않아도 무료 공유 분석 서버로 바로 사용할 수 있어요(Cloudflare Workers 경유). 공유 분석은 IP당 1일 10회, 전체 1일 100회로 제한될 수 있어요(실제 제한은 서버에서 적용돼요). 더 자주 쓰고 싶다면 아래에 본인 API Key를 등록하면 그 키로 우선 분석해요.

키는 본인 브라우저(LocalStorage)에만 안전하게 저장되며 외부로 유출되지 않습니다.

구글 한도가 끝나거나 오류가 나면 OpenRouter 무료 모델(Qwen, Gemma)로 자동 전환돼요. 키 하나만 넣어도 동작해요. 무료 모델은 요청 내용이 제공사에 기록될 수 있어요.

촬영한 사진은 분석을 요청하는 순간에만 전송돼요. 공유 모드는 Cloudflare 프록시를 거쳐 Google/OpenRouter로 전달되고, 개인 키 모드는 Google/OpenRouter로 직접 전달돼요. 어느 경우에도 서버에 사진을 저장하지 않으며, 진단 기록은 이 기기의 브라우저에만 저장돼요.
